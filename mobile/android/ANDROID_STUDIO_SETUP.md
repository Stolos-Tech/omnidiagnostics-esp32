# Android Studio — покроково (для того, хто ще не працював)

## Як ми співпрацюємо (важливо)
Я **не підключаюсь** до Android Studio. Я редагую файли коду в цій теці репозиторію
(`mobile/android/`). Ти відкриваєш **ЦЮ САМУ теку** в Android Studio й збираєш/запускаєш.
Коли я щось міняю — ти в Studio робиш `File → Sync Project with Gradle Files` (або просто
перезбираєш), і зміни підхоплюються. Тобто спільна тека = наша «точка з'єднання».

---

## 1. Встановити Android Studio
- Завантаж: https://developer.android.com/studio (безкоштовно, Windows).
- Встанови зі стандартними опціями. При першому запуску воно **саме завантажить Android SDK**
  (кілька ГБ) — просто погоджуйся (Next/Accept). Це разова процедура.

## 2. Відкрити проєкт
- `File → Open` → вибери теку **`C:\Users\danii\Desktop\ESP32 OS\ESP32 OS\mobile\android`**
  (саме `android`, не `mobile`). OK.
- Внизу піде **Gradle Sync** (завантаження залежностей: Compose, OkHttp тощо) — 2-10 хв першого разу.
  Якщо запитає встановити SDK-компонент / прийняти ліцензію — погоджуйся.
- Якщо червоні помилки після синку — часто це «Install missing SDK» лінк прямо в помилці; тисни його.

## 3. Підключити телефон
**Варіант A — USB (найпростіше):**
1. На телефоні: `Налаштування → Про телефон → тапни 7 разів по "Номер збірки"` → з'явиться
   «Режим розробника».
2. `Налаштування → Система → Для розробників → увімкни "Налагодження USB (USB debugging)"`.
3. Під'єднай телефон кабелем до ПК, на телефоні дозволь «Debugging».
4. У Android Studio вгорі у списку пристроїв з'явиться твій телефон.

**Варіант B — WiFi (без кабелю):** у «Для розробників» увімкни «Wireless debugging», у Studio
`Device Manager → Pair using Wi-Fi`.

## 4. Запустити
- Вгорі обери свій телефон + натисни зелений **▶ Run** (Shift+F10).
- Studio збере APK, встановить і запустить на телефоні. Перший білд ~кілька хв, далі швидко.

## 5. Під'єднатися до плати
У додатку:
- **Локально** (телефон у тій самій WiFi, що й плата, АБО на точці плати `OmniDiag-Setup`):
  тисни **FIND** (mDNS знайде плату) або впиши **Host** `192.168.50.53` + **PIN** `036163` → **CONNECT**.
- **Здалеку** (пізніше, коли підіймемо Tailscale-шлюз на сервері): Host = Tailscale-IP шлюзу, порт 8443,
  + токен у налаштуваннях безпеки.

## Якщо щось не так
- **«SDK location not found»** → Studio запропонує встановити; погодься. Або `Tools → SDK Manager`.
- **Gradle sync failed** → перевір інтернет; `File → Invalidate Caches / Restart`.
- **Додаток не бачить плату** → телефон і плата в одній мережі? `usesCleartextTraffic` уже дозволено
  (плата по HTTP). Спробуй ручний Host замість FIND.
- **Мінімальна версія Android** — 8.0 (API 26). Старіші не підтримуються.
