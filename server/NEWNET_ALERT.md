# Алерт «чужий пристрій» на новій квартирі (HUAWEI-dv7W-2G)

Переїзд на нову квартиру → мережа `192.168.100.0/24`, роутер HUAWEI `192.168.100.1`.
Плата (ESP32) прописана в мережу, IP `192.168.100.41` (STA) + AP `OmniDiag-Setup`.

## Логіка (краще за «історію з роутера»)
Не «прийняти тихо все, що є» (звичайний baseline), а **білий список = мої пристрої;
алерт на будь-що інше**. Реалізовано: `netwatch.foreign_devices()` + `load_trusted()`,
вмикається у collector прапорцем `alert_untrusted`. Тоді пристрій попереднього мешканця,
що перепідключиться, одразу алертне (його нема в білому списку).

## Move-in baseline (скан 192.168.100.x на момент заселення — усе МОЄ)
| IP            | MAC                 | що це                         | у білий список |
|---------------|---------------------|-------------------------------|----------------|
| 192.168.100.1 | 90:3F:EA:4C:28:0B   | роутер HUAWEI (шлюз)          | так            |
| 192.168.100.37| F8:FE:5E:8A:3C:DE   | ПК (Intel)                    | так            |
| 192.168.100.41| (MAC плати ESP32)   | плата ESP32-OS                | так            |
| 192.168.100.36| 6E:95:4A:C4:75:46   | телефон (РАНДОМНИЙ MAC 6E)    | * див. нижче   |

\* Телефон використовує рандомізацію MAC — його MAC змінюється й не годиться для білого
списку. Варіанти: (а) вимкнути рандомізацію MAC саме для цієї мережі в налаштуваннях
телефона (Android: WiFi → мережа → Privacy → Use device MAC); (б) лишити `skip_random=True`
(рандомні MAC ігноруються в алерті — тоді власний телефон не смітить, але й чужий телефон
з рандомізацією не спіймається — компроміс).

## Активація (коли сервер повернеться) — config.json:
```json
"alerts": {
  "alert_untrusted": true,
  "alert_random_mac": false,          // true щоб ловити й рандомні (з ризиком шуму від свого тел.)
  "trusted_macs": ["90:3F:EA:4C:28:0B", "F8:FE:5E:8A:3C:DE", "<MAC_плати>"]
}
```
+ у БД познач свої СТАРІ пристрої `trust='trusted'` (POST /lib/devices/<id>/trust?trust=trusted)
— тоді вони теж у білому списку автоматично. Далі collector алертить будь-що не-довірене.

## Опційно: head-start зі старих пристроїв роутера
Щоб знати «привидів» попереднього мешканця ДО того, як вони з'являться — потрібен логін
адмінки HUAWEI (192.168.100.1) → експорт списку пристроїв (DHCP-lease / attached devices) →
імпорт у watchlist. БЕЗ адмін-доступу цього зробити не можна (дай логін або встав список).
